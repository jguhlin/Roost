## Phase 2 — The history problem (BLOCKER: must choose A or B)

`.git` is **4.8 GB packed / 226 commits**. GitHub blocks files >100 MB and
pushes >2 GB. History contains:

- 1.2 GB `orthofinder/…_core.tar.zst`, 495 MB `SequenceIDs.txt`, 344 MB MSA fasta, …
- 72 MB PDFs, 165/151/134/107 MB zips
- **`web/.env` with the Movebank token** (introduced in commit `2a17191d`)
- all 358 copyrighted PDFs

### Option A — Fresh history (RECOMMENDED)

Simplest, provably clean: the 226 commits are local-iteration history of a
private workspace; nothing external depends on the hashes.

```bash
# from a clean working tree
git checkout --orphan github-main
git add -A                      # respects the new .gitignore
git commit -m "Roost: initial public commit"
# verify, then make it the only branch:
git branch -D main
git branch -m main
git reflog expire --expire=now --all && git gc --prune=now --aggressive
du -sh .git                     # must be small (<200 MB expected)
```

Keep the old history around locally first if wanted:
`git branch archive-private main` **before** the rewrite (do not push it).

### Option B — Rewrite history with git-filter-repo (keeps 226 commits)

```bash
pip install git-filter-repo
git filter-repo --force \
  --path pdfs_to_process --path orthofinder --path verso_workspace \
  --path to_process --path download_tmp --path .ralph \
  --path web/dist-verify --path web/playwright-report --path web/.env \
  --path web/public/species --path web/public/data --path test-results \
  --path-glob '*.zip' --path-glob '*.pdf' \
  --strip-blobs-bigger-than 10M \
  --invert-paths
du -sh .git   # verify <2 GB, spot-check `git log --all -- web/.env` is empty
```

Caveats: renamed/moved paths can survive glob misses; needs a careful audit
afterward (`git rev-list --objects --all | git cat-file --batch-check…` size
report). More work, more residual risk, keeps commit messages (which
themselves may reference private paths — cosmetic only).
